# Calculator Pro

A modern scientific calculator web application built with TypeScript and React.

## Features

- Scientific calculation support
- Clean and responsive UI
- Built with modern web technologies

## Tech Stack

- **TypeScript**
- **React**
- **Vite**

## Getting Started

### Prerequisites

- Node.js installed on your machine

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Guruprasad1782011/calculator-pro.git
   cd calculator-pro
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local URL shown in the terminal.
